# Fruit Ninja (Browser Clone)

A single-file HTML5 canvas game — slice the fruit, dodge the bombs. No build step, no dependencies; just open `index.html` or play the live demo.

**▶️ Play:** https://fruit-ninja-xi-jade.vercel.app

## Run locally

```bash
# any static server works
python3 -m http.server 8000
# then open http://localhost:8000
```

## Built with

- HTML5 Canvas
- Vanilla JavaScript (no framework)
